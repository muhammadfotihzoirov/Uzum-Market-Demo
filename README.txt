UZUM MARKET DEMO
================

Ishga tushirish:
1. ZIP faylni oching (Extract All).
2. Papkani VS Code orqali oching.
3. index.html faylini Live Server bilan ishga tushiring.
   Live Server bo‘lmasa, index.html ni Chrome’da ochishingiz mumkin.

Demo admin:
Login: admin
Parol: uzum123

Nimalar bor:
- 200 ta demo mahsulot va kategoriyalar
- Qidiruv (nom, kategoriya, tavsif)
- Kategoriya filtri va narx/reytинг/chegirma bo‘yicha saralash
- Savatcha, miqdor, o‘chirish, demo checkout
- Sevimlilar
- Demo profil va buyurtma tarixi
- Admin panel: mahsulot qo‘shish/o‘chirish, buyurtma statusini o‘zgartirish
- Responsive dizayn

MUHIM:
Bu mustaqil o‘quv/demo loyiha. Uzum Marketning rasmiy mahsuloti emas.
Buyurtma, login, to‘lov yoki serverga haqiqiy ma’lumot yuborilmaydi.
Ma’lumotlar brauzer localStorage ichida saqlanadi. Supabase hozir ulanmagan.
Mahsulot kartalaridagi rasmlar emoji fallback bilan ko‘rsatiladi; admin orqali rasm URL kiritish mumkin.
